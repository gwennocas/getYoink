## Default Permission

Permite downloads públicos e atualização do yt-dlp.

#### This default permission set includes the following:

- `allow-inspect-video`
- `allow-download-video`
- `allow-download-progress`
- `allow-engine-status`
- `allow-update-engine`
- `allow-open-download-folder`
